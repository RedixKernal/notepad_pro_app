Notepad_Pro Usage Instructions

Welcome to Notepad_Pro!

Usage:
1. Open the application.
2. Use "Open Folder" or "Open File" from the File menu to begin.
3. Your work is automatically saved if Auto Save is enabled.
4. Use the sidebar to navigate your project directory.
5. You can toggle themes via the Theme button in the toolbar.
